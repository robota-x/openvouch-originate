# Architecture Decision Records

This directory contains ADRs (Architecture Decision Records) for the defi-hack project.

## Format

Each ADR is a Markdown file named `NNN-short-title.md` with the following sections:

### Title
A short noun phrase describing the decision.

### Status
One of: `proposed` | `accepted` | `deprecated` | `superseded`

### Context
What is the issue that motivated this decision? What forces are at play?

### Decision
What was decided? State it in full sentences, in active voice.

### Consequences
What becomes easier or more difficult as a result of this change?
